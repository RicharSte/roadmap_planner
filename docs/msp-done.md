# MSP — определение готовности (релиз 1.0.0)

MSP = Minimum Selling Product. Проект готов к релизу, когда отмечены **все** пункты.
Пункты отмечает агент при закрытии задачи (`/task-build`), только если пункт реально проверен.
Этапы закрываются по порядку: задачи этапа N+1 не берутся, пока раздел этапа N не отмечен целиком.
