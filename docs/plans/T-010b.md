# T-010b: UI — редактор описания, предпросмотр, подтверждение удаления

Статус: approved

## Проблема

Пользователь не может создать описание ноды, отредактировать его и увидеть предпросмотр; удаление ноды
происходит сразу, без подтверждения, и оставляет файлы описаний. Не закрыты пункты `mvp-done.md`:
«Создать описание ноды…» и «Удалить ноду с подтверждением…». Rust и storage готовы в T-010.
Правила жизненного цикла файлов — ADR 0013.

## Решения из интервью

- Зависимости: `@uiw/react-codemirror`, `@codemirror/lang-markdown`, `react-markdown`, `remark-gfm` (ADR 0006).
- «Создать описание» в панели при `descriptionPath === null`: `writeDescription(path, "")`, затем
  `setDescriptionPath` и сохранение `roadmap.json`. Ошибка записи файла → ничего не меняется, баннер `saveError`.
- Сохранение текста — при blur редактора и при переключении ноды; без кнопки и debounce (T-011). Ошибки — баннер.
- Правка описания **не** меняет `updatedAt` и не пишет `roadmap.json`.
- Переключатель «Редактор / Просмотр». При открытии: текст не пустой → «Просмотр»; пустой/новый → «Редактор».
- Предпросмотр: ссылки — текст без перехода, картинки — alt-текст, сырой HTML не рендерится (без `rehype-raw`).
- Нет файла → пустой редактор + «Файл не найден, будет создан при сохранении». `NOT_UTF8`/`FILE_TOO_LARGE` →
  сообщение об ошибке, редактор только для чтения.
- Удаление: встроенный блок подтверждения в панели при **каждом** удалении, без склонений:
  «Удалить «<title>»? Будет удалено нод: N (из них дочерних: K), файлов описаний: M.» + «Удалить» / «Отмена».
  Порядок: `roadmap.json` → `deleteDescriptions`. Сбой удаления файлов → сироты, баннер.
- Тесты: в `App.test.tsx` `@uiw/react-codemirror` подменяется `<textarea>` (`vi.mock`); настоящий редактор — вручную.

## Решение

`useProject`: `update` возвращает `boolean` (успех сохранения). Новые колбэки: `createDescription(id)`,
`loadDescription(path)` (проброс `readDescription`), `saveDescription(path, content): Promise<boolean>`
(ошибка → `saveError`). `deleteNode` собирает пути описаний ветки до удаления, после успешного `update`
вызывает `deleteDescriptions`; его ошибка → `saveError`. UI по-прежнему не импортирует `@tauri-apps`.

`DescriptionEditor.tsx` (новый): пропсы `path`, `onLoad`, `onSave`. Монтируется с `key={node.id}`, поэтому
при смене ноды пересоздаётся. Состояния: загрузка / готов / нет файла / ошибка (read-only). `draft` и
`saved` в state; blur обёртки → если `draft !== saved`, `onSave`, при успехе `saved = draft`. При размонтировании
с несохранённым `draft` — `onSave` через ref (переключение ноды). Ответ загрузки после размонтирования
игнорируется. CodeMirror: `markdown()`, `EditorView.lineWrapping`, без номеров строк и folding.
Предпросмотр: `ReactMarkdown` + `remarkGfm`, `components.a` → `<span>`, `components.img` → `<span>{alt}</span>`.

`DetailsPanel`: вместо строки «Описание: …» — кнопка «Создать описание» или `DescriptionEditor`. «Удалить»
показывает блок подтверждения; счётчики считаются чистой доменной `deleteNode(project, id).deletedIds`
без сохранения. `App.tsx` пробрасывает колбэки. Отклонено: тесты с настоящим CodeMirror в jsdom — хрупко.

## Тесты

`App.test.tsx` (storage замокан: `readDescription`, `writeDescription`, `deleteDescriptions`; CodeMirror → textarea):
загрузка — `loaded` непустой → «Просмотр» с текстом; `missing` → пометка и «Редактор»; `NOT_UTF8` → ошибка,
textarea `readOnly`. Сохранение — правка + blur → `writeDescription(path, text)`; blur без правки → нет вызова;
правка + выбор другой ноды → вызов; сбой записи → `save-error-banner`. Создание — `writeDescription(path, "")`
вызван раньше `saveProject`, в проекте `descriptionPath`; сбой записи → `saveProject` не вызван, баннер.
Предпросмотр — ссылка без `<a>`, картинка без `<img>` (виден alt), `<b>x</b>` не элемент, GFM-таблица → `<table>`.
Удаление — блок с «нод: 3 (из них дочерних: 2), файлов описаний: 1» для `n_root`; «Отмена» → `saveProject` не
вызван; «Удалить» → `saveProject`, затем `deleteDescriptions(["descriptions/n_child1.md"])`; сбой `saveProject` →
`deleteDescriptions` не вызван; сбой `deleteDescriptions` → баннер, дерево обновлено.

## Вне рамок

Debounce, индикатор несохранённого, предупреждение при закрытии (T-011); перезагрузка с диска (T-012);
склонения и финальные тексты ошибок (T-013); клик по чекбоксам GFM в предпросмотре; split-режим.

## Риски и вопросы

- Repowise: `App.test.tsx` — hotspot 96 %, `useProject.ts` 67 %, `App.tsx` 54 %, `DetailsPanel.tsx` 46 %
  (`DetailsPanel`/`useProject` — large method); все пятеро меняются вместе — все в плане.
  `DetailsPanel` растёт — редактор вынесен в отдельный файл.
- `EditorView` импортируется из `@uiw/react-codemirror` (реэкспорт `@codemirror/view`). Если реэкспорта нет —
  стоп и вопрос, не добавлять `@codemirror/view` самовольно.
- Сохранение при размонтировании — fire-and-forget; при открытии другой папки blur срабатывает раньше
  (клик по кнопке «Открыть папку…»), поэтому запись идёт в старый проект. Проверить вручную.
- Закрытие окна с несохранённым текстом в фокусе теряет правку — закрывает T-011.
