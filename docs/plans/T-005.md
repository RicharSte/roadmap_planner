# T-005: Rust — открыть папку проекта, прочитать `roadmap.json`, path-safety helper + тесты

Статус: approved

## Проблема

Домен (T-004) умеет разбирать проект, но открыть его с диска пока нельзя: в Rust нет ни одной реальной команды,
а `src/storage/` пуст. Без этого не будет сценария «Открыть существующий проект выбором папки» и пункта 24 `mvp-done.md`.
Кроме того, T-006 и T-010 нужен проверенный helper, который не выпускает пути за пределы папки проекта.

## Решения из интервью

- Q1 Папку выбирают в диалоге `tauri-plugin-dialog`, который вызывается только из Rust. В диалоге есть кнопка «Новая папка».
  Фронтенд путь не передаёт, JS-разрешений `dialog:*` нет. Если папка невалидна, UI просит выбрать другую (это T-008).
- Q2 Корень хранится в состоянии Rust. Q3 Rust возвращает сырой текст JSON, валидирует только домен (`parseProject`).
- Q4 Ошибки имеют вид `{ code, message }`, сообщение на английском. Отмена диалога — не ошибка: команда возвращает `null`.
- Q5 `resolve_inside`: путь не пустой и относительный; без `\`, `:`, без компонентов `.`/`..` и пустых;
  ближайший существующий предок канонизируется и обязан лежать внутри корня (ловит symlink наружу). Q6 TS-адаптер входит в задачу.
- Q7 `tempfile` подключается как dev-dependency. Q8 Лимит `roadmap.json` — 10 МБ (≈30 000 узлов).
- Q9 Двухфазное открытие: кандидат `pending` → `commit_project` после успешного `parseProject`. Если проверка не прошла,
  ранее открытый проект остаётся открытым. Q10 Различаем `EMPTY_FOLDER` (скрытые файлы `.*` не считаются) и `NO_ROADMAP_FILE`. Пустая папка тоже становится `pending` (вид `Empty`) — под T-007, ADR 0009.
- Q11 Стартовый экран и повторный выбор папки — T-008, создание проекта — T-007, русские тексты — T-013. Q12 `reload_project` входит в задачу.

## Решение

`paths.rs` — чистая функция `resolve_inside(root, rel)`. `project.rs` содержит `ProjectState { pending: (папка, вид Roadmap | Empty), root }` под `Mutex`
и три команды. `open_project` (async) открывает диалог, канонизирует папку, вызывает `read_roadmap(dir)` и запоминает `pending`.
`commit_project` переносит в `root` только `pending` вида `Roadmap`. `reload_project` вызывает `read_roadmap(root)`. Логика чтения и состояния —
обычные функции, команды только склеивают их с Tauri, поэтому всё тестируется без окна. `src/storage/projectStorage.ts`:
`openProject()` и `reloadProject()` = `invoke` → `JSON.parse` → `parseProject` → `commit_project` (только при открытии).
Отклонено: путь от JS (недоверенный ввод) и разбор схемы через serde (вторая валидация рядом с доменом).

## Тесты

- `resolve_inside`: `descriptions/a.md` (ещё не существует) → путь внутри; пустой путь, абсолютный, `../x`, `a/../b`, `./a`, `a\b`, `C:a` → `INVALID_PATH`;
  symlink на папку снаружи (`#[cfg(unix)]`) → `PATH_OUTSIDE_PROJECT`; symlink внутрь проекта → разрешён.
- `read_roadmap`: валидный файл → текст; не папка → `NOT_A_DIRECTORY`; пусто и только `.DS_Store` → `EMPTY_FOLDER`; есть файлы,
  но нет `roadmap.json` → `NO_ROADMAP_FILE`; `roadmap.json` — это папка → `IO_ERROR`; 10 МБ + 1 байт → `FILE_TOO_LARGE`; не UTF-8 → `NOT_UTF8`.
- `ProjectState`: `commit` без `pending` → `NO_PENDING_PROJECT`; `commit` при `pending` вида `Empty` → `PENDING_NOT_PROJECT`; новый `pending` заменяет старый, `root` не трогает; `reload` без `root` → `NO_PROJECT_OPEN`.
- Адаптер: `null` → `cancelled`, без commit; валидный JSON → `opened` + вызван `commit_project`; битый JSON → `INVALID_JSON`;
  `parseProject` вернул проблемы → `INVALID_PROJECT` + `problems`, commit не вызван; ошибка Rust → тот же `code`; `reloadProject` никогда не вызывает commit.

## Риски и вопросы

- Если в `tauri-plugin-dialog` 2 нет `set_can_create_directories`, проверить: на macOS кнопка «Новая папка» в NSOpenPanel может быть включена и по умолчанию; если её нет совсем — спросить пользователя.
- `blocking_pick_folder` нельзя вызывать в главном потоке (зависание на macOS): команда `open_project` обязана быть `async`.
- Если после «Перезагрузить» JSON битый, `root` остаётся открытым. Защита от перезаписи автосохранением внесена в строку T-012 в backlog.
- Модель доступа к файлам зафиксирована в ADR 0009 (добавлен после первого одобрения). `create_project` — не здесь, это T-007.
