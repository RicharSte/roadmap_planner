# T-013: Понятные пользователю тексты ошибок storage/UI

Статус: approved

## Проблема

Баннеры ошибок (`error`, `reloadError`, `saveError` в `App.tsx`) показывают `error.code`
(`IO_ERROR`, `NOT_A_DIRECTORY`, ...) и `error.message` как есть. `message` приходит либо из Rust
(`AppError`, нарочно на английском — `src-tauri/src/paths.rs:5-6`, независимость от локали ОС),
либо захардкожен на английском в `src/storage/projectStorage.ts` (`"roadmap.json is not valid
JSON"` и т.п.). Пользователь без английского не поймёт, что случилось. Домен (`DomainError`,
`problems[]`) уже на русском — проблема только в слое storage/UI.

## Решения из интервью

- Rust и `src/domain/` не трогаем. Русификация — только маппинг код→текст на фронте.
- Новый модуль `src/ui/strings.ts` сейчас заводим только с текстами ошибок (не весь UI-текст —
  полный перенос кнопок/диалогов рискует регрессиями в hotspot-файлах и выходит за лимит плана).
  Это частичное закрытие Q9 (`docs/open-questions.md`) — отмечено в `docs/later.md`.
- `error.code` остаётся в баннере мелкой технической подписью под русским текстом (пригодится для
  багрепортов), не убираем из DOM.
- `FILE_TOO_LARGE` переводим с конкретным числом «10 МБ» (сейчас у всех трёх лимитов в Rust
  одинаковое значение `10 * 1024 * 1024`).
- Ошибки домена (`saveError.code === "DOMAIN"`) и `problems[]` (валидация `roadmap.json`) не
  трогаем — уже на русском.
- Решение зафиксировать ADR 0016 (не 0015 — это число уже упомянуто в `docs/later.md:302` для
  отдельного решения про блокировку записи при ошибке reload).

## Решение

`src/ui/strings.ts` экспортирует `Record<StorageErrorCode, string>` (все 16 кодов из
`projectStorage.ts`) и функцию `getStorageErrorMessage(code)`. `App.tsx` для `error`/`reloadError`/
`saveError` вычисляет текст: `code === "DOMAIN" ? message : getStorageErrorMessage(code)` — и
показывает его вместо `error.message`; `error.code` остаётся рядом мелким текстом.

Тексты (по `StorageErrorCode`):

- `INVALID_PATH` — «Указан недопустимый путь к файлу.»
- `PATH_OUTSIDE_PROJECT` — «Путь ведёт за пределы папки проекта — доступ запрещён.»
- `NOT_A_DIRECTORY` — «Выбранный путь не является папкой.»
- `EMPTY_FOLDER` — «Папка пуста.»
- `NO_ROADMAP_FILE` — «В выбранной папке нет файла roadmap.json.»
- `IO_ERROR` — «Не удалось прочитать или записать файл на диске.»
- `FILE_TOO_LARGE` — «Файл превышает лимит 10 МБ.»
- `NOT_UTF8` — «Файл повреждён: в нём недопустимые символы (ожидается текст в UTF-8).»
- `NO_PENDING_PROJECT` — «Папка для создания проекта не выбрана. Нажмите «Открыть папку…» снова.»
- `PENDING_NOT_PROJECT` — «Выбранная папка не содержит проект и не пуста.»
- `PENDING_NOT_EMPTY` — «Выбранная папка уже содержит проект.»
- `FOLDER_NOT_EMPTY` — «Папка больше не пуста. Выберите другую папку.»
- `NO_PROJECT_OPEN` — «Проект не открыт.»
- `INVALID_JSON` — «Файл roadmap.json повреждён: это не корректный JSON.»
- `INVALID_PROJECT` — «Файл roadmap.json содержит некорректные данные проекта.»
- `READ_ONLY` — «Файл доступен только для чтения — запись невозможна.»

Отклонённая альтернатива: хранить тексты прямо в `App.tsx` — отклонено, т.к. `strings.ts` даёт
точку расширения для будущего i18n (Q9) и для новых кодов в 1.1/1.2 (ADR 0016).

## Критерии приёмки

- [ ] Баннер `error`/`reloadError`/`saveError` показывает русский текст из `strings.ts` вместо
      `error.message`, когда `code !== "DOMAIN"`.
- [ ] `error.code` виден в DOM мелкой подписью (тест через `data-testid`/класс, не через текст
      сообщения).
- [ ] Для `code === "DOMAIN"` баннер показывает `error.message` как раньше (без изменений).
- [ ] `FILE_TOO_LARGE` → текст содержит «10 МБ».
- [ ] `getStorageErrorMessage` покрывает все 16 значений `StorageErrorCode` (тест проверяет
      отсутствие `undefined` для каждого кода — TS уже не даст забыть код благодаря `Record`).
- [ ] `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm format:check` проходят.
- [ ] `cargo test`, `cargo clippy --all-targets -- -D warnings` проходят без изменений в
      `src-tauri/` (без изменений в коде).
- [ ] Ручная проверка: открыть несуществующую/битую папку → баннер на русском, без английских фраз.

## Файлы

- `src/ui/strings.ts` — создать — маппинг `StorageErrorCode → string`, `getStorageErrorMessage`.
- `src/ui/strings.test.ts` — создать — все 16 кодов дают непустую строку; `FILE_TOO_LARGE` содержит
  «10 МБ».
- `src/App.tsx` — изменить — рендер баннеров через `getStorageErrorMessage`, код — мелкой подписью.
- `src/App.test.tsx` — изменить — обновить тест, завязанный на `toHaveTextContent("INVALID_JSON")`
  (строка 1078), на новый русский текст; код проверять отдельным запросом.
- `docs/decisions/0016-user-readable-error-messages.md` — создать — ADR: Rust/domain без изменений,
  русификация — маппинг код→текст в `src/ui/strings.ts`, новый `AppError`-код = новая запись.

## Шаги

1. `src/ui/strings.ts`: типы, `Record<StorageErrorCode, string>` с текстами выше,
   `getStorageErrorMessage`.
2. `src/App.tsx`: для трёх баннеров заменить `{error.message}` на вычисленный текст, оставить
   `error.code` отдельным `<span>` ниже/рядом (без изменения структуры `problems[]`).
3. `src/App.test.tsx`: обновить тест строки 1078 на новый текст; добавить 1-2 проверки (например,
   `NOT_A_DIRECTORY` → текст на русском, код виден отдельно).
4. `src/ui/strings.test.ts`: тест на полноту маппинга и текст `FILE_TOO_LARGE`.
5. ADR 0016.
6. `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm format:check`; `cargo test`, `cargo clippy`
   (ожидается 0 diff, но прогнать для подтверждения).

## Тесты

- `getStorageErrorMessage`: по каждому из 16 кодов возвращает непустую русскую строку;
  `FILE_TOO_LARGE` содержит «10 МБ».
- `App.test.tsx`: баннер открытия/перезагрузки/сохранения показывает русский текст для нескодового
  (не `DOMAIN`) кода; `DOMAIN`-ошибка показывает `error.message` без изменений; `error.code` найден
  в DOM отдельно от текста сообщения.

## Вне рамок

- Переписывание сообщений Rust (`AppError`) и домена (`DomainError`, `validate.ts`) — остаются как
  есть (по решению из интервью).
- Полный перенос всех UI-строк (кнопки, диалоги) в `strings.ts` — отдельная задача, добавлена в
  `docs/later.md`.
- Визуальное отключение кнопок при ошибке/`locked` — уже в `docs/later.md` из T-012, не сюда.
- Локализация на другие языки (EN и т.д.) — вне MVP, перенесена в 1.2 (T-209; платформы — Q13, 2.0).
