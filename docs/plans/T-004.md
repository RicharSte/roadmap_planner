# T-004: `src/domain/` — типы, индекс родителей, операции над узлами, валидация (ADR 0005) + тесты

Статус: approved

## Проблема

Формат проекта описан в ADR 0005, но кода нет: ни типов, ни операций над деревом, ни проверки загружаемого `roadmap.json`. Без домена не написать ни Rust-чтение (T-005), ни UI (T-008, T-009): по жёсткому правилу AGENTS весь доступ к структуре идёт только через функции домена, а не через сырой JSON.

## Решения из интервью

- Q1 Чистые функции, новый `Project` со structural sharing: новые только объект проекта, карта `nodes` и изменённые
  узлы, глубокое клонирование запрещено. Это же даёт корректную перерисовку React по ссылке и не закрывает undo.
- Q2 Операции бросают `DomainError` с машинным `code`; `parseProject` не бросает, а возвращает список проблем — нужно
  для пункта 24 `mvp-done.md`. Q11 В ошибке только `code` + сообщение по-английски, русские тексты в UI (T-013).
- Q3 Индекс родителей — чистая `buildParentIndex(project)`, кэш снаружи (`useMemo` по ссылке на проект); класс с
  внутренним кэшем отклонён: второй источник истины и риск устаревания. Q4 Свой генератор id, без зависимостей.
- Q5 `deleteNode` удаляет поддерево и возвращает `deletedIds` (для очистки `descriptions/`). Q6 `moveNode(project, id, newParentId | null, index?)`:
  `null` — в корни, без `index` — в конец, запрет переноса в себя и в потомка; тот же вызов переставляет узел внутри родителя.
- Q7 Парсинг untrusted JSON в домене, `version !== 1` → `UNSUPPORTED_VERSION`, миграций нет. Q8 Плюс `setStatus` и
  `setDescriptionPath` (иначе T-009/T-010 полезут в сырой JSON). Q9 Время — параметр `now?: string`. Q10 Раскладка (A).
- Q12 `title`: trim, `\r\n` → пробел, пусто → `EMPTY_TITLE`, > 120 символов → `TITLE_TOO_LONG`; то же в `renameNode`,
  дефолт «Новый узел» подставляет UI. Q13 Все проблемы списком, лишние поля отброшены, авторемонта нет. Q14, Q15 — да.

## Решение

Четыре модуля без побочных эффектов и без импортов Tauri. `types.ts` — форма данных (`Project`, `RoadmapNode`,
`NodeStatus`, `ParentIndex = Map<string, string[]>`, класс `DomainError` и union кодов). `ids.ts` — `createNodeId(nodes)`:
префикс `n_` + 10 символов алфавита `0-9a-z` без похожих букв (`i l o u`), повтор при коллизии. `validate.ts` —
`parseProject(raw: unknown)` и `validateProject`, оба возвращают `{ ok: true, project } | { ok: false, problems }`.
`tree.ts` — `buildParentIndex`, `getParents`, `getChildren`, `createNode`, `renameNode`, `deleteNode`, `moveNode`, `setStatus`,
`setDescriptionPath`. `ParentIndex` сразу хранит массив родителей, хотя v1 проверяет «не больше одного»: переход к графу v2 не меняет подписи. Отклонено: мутирующий API — ломает React и будущий undo.

## Критерии приёмки

- [ ] `pnpm test` зелёный, один прогон; покрыты все 9 публичных функций `tree.ts` и обе из `validate.ts`.
- [ ] `pnpm typecheck`, `pnpm lint`, `pnpm format:check` зелёные; `grep -rn "@tauri-apps\|invoke(" src/domain/` — пусто.
- [ ] Пример `roadmap.json` из ADR 0005 проходит `parseProject` → `ok: true`, 2 узла, `rootIds: ["n_a"]`.
- [ ] Повреждённые данные (несуществующий id, два родителя, цикл, `version: 2`) → `ok: false`, `problems` с ожидаемыми кодами, входной объект не изменён.
- [ ] Нет мутации входа: `Object.is(before.nodes, after.nodes) === false`, но нетронутый узел — та же ссылка.
- [ ] Все экспортируемые функции имеют `/** */`-комментарий на русском (правило AGENTS).

## Тесты

- `parseProject`: пример из ADR; не-объект; нет обязательных полей; `version: 2`; две проблемы сразу; лишние поля
  отброшены. `validateProject`: несуществующий id, два родителя, сирота, цикл `a → b → a`, дубликат в `childrenIds`, `descriptionPath: "../secret.md"`.
- `buildParentIndex` / `getParents` / `getChildren`: корень, лист, неизвестный id.
- `createNode`: в корень, к родителю, `index` в середину, пустой и 121-символьный `title`, `\n` в заголовке.
- `renameNode`: обычный, ошибки заголовка, `updatedAt` меняется при фиксированном `now`.
- `deleteNode`: лист, поддерево из 3 узлов (состав `deletedIds`), корневой узел, неизвестный id.
- `moveNode`: к другому родителю, в корни (`null`), перестановка внутри родителя, в себя, в потомка, `index` вне диапазона, неизвестный родитель.
- `setStatus`: валидный и невалидный статус. `setDescriptionPath`: первый раз, повтор, другой путь. `createNodeId`: префикс, алфавит, уникальность на 1000 вызовов.

## Вне рамок

Storage/Tauri и файловый ввод-вывод (T-005, T-006), создание `descriptions/<id>.md` на диске (T-010), миграции (версии 2 нет),
UI (T-008, T-009), undo/redo, граф с несколькими родителями, `fast-check`, кэш индекса в домене, тексты ошибок для пользователя (T-013).

## Риски и вопросы

- `crypto.getRandomValues` должен быть доступен в jsdom; если нет — тест упадёт сразу, тогда берём webcrypto из
  `node:crypto` внутри `ids.ts`, без правки окружения тестов. Лимит заголовка домен только проверяет, обрезает UI (T-009).
- API домена зафиксирован в ADR 0008 (чистые функции, `DomainError` с кодами, внешняя мемоизация индекса) — написан по
  просьбе пользователя после одобрения плана, `docs/open-questions.md` Q7. Реализация обязана ему соответствовать.
