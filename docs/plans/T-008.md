# T-008: UI — дерево в сайдбаре + панель деталей (ADR 0004)

Статус: approved

## Проблема

В приложении демо-экран шаблона: домен и чтение/создание проекта готовы (T-004…T-007), но открыть проект
и увидеть дерево нельзя. Нет базы для T-009/T-010, пункты `mvp-done.md` об открытии не проверить.

## Решения из интервью

- Объём: только просмотр. Правки — T-009, редактор описаний — T-010.
- Одна кнопка «Открыть папку…». На `EMPTY_FOLDER` появляется «Папка пуста. Создать в ней новый проект?»
  с кнопками [Создать] / [Отмена]; [Создать] вызывает `createProject()`.
- Состояние и действия — в хуке `useProject`, компоненты получают только props. Задел под T-009: там в хук
  добавится одна функция `update(op)` для чистых доменных операций; при тесноте `useState` переходит
  на `useReducer` внутри хука. В T-008 `update` не пишем (нет вызывающих).
- Сворачивание: при открытии всё раскрыто, свёрнутые id только в памяти.
- Строка дерева: треугольник (если есть дети) + точка статуса с подсказкой + название. Цвета: `unstarted`
  серый, `in progress` синий, `paused` красный, `done` зелёный; подписи «Не начато / В работе / На паузе /
  Готово». Внизу сайдбара — легенда (точка + подпись). Клавиатура: только нативные `<button>`.
- Детали: «Выберите ноду» / «В проекте нет нод»; у выбранной — название, статус (точка + подпись),
  «Создано / Изменено» (`toLocaleString`), «Описание: нет» или путь файла.
- Ошибки: баннер «Не удалось открыть проект» + `code` + `message`, для `INVALID_PROJECT` — список `problems`.
  Прежний проект остаётся на экране. Отмена диалога ничего не показывает.
- `App.tsx`/`App.css` заменяются; `greet`, `opener`, `react.svg` — T-101. Строки на русском в компонентах
  (модуль строк — T-013). Выбор сбрасывается при открытии.
- Ресайз сайдбара мышью: свой разделитель, от 180px до 60% окна, старт 280px, без сохранения.
  Узкое окно: детали сжимаются до ~320px, дальше горизонтальный скролл.

## Решение

`useProject()` хранит `project`, `selectedId`, `collapsed`, `error`, `pendingCreate`; `parentIndex` через
`useMemo(buildParentIndex)` (ADR 0008); действия `open`, `create`, `cancelCreate`, `select`, `toggle`. `TreeSidebar` рекурсивно рендерит `rootIds` → `getChildren`, `DetailsPanel`
показывает выбранную ноду. `App` собирает раскладку и разделитель (mousedown → mousemove на `window`
→ mouseup). Цвет точки — CSS по `data-status`. Отклонено: `react-resizable-panels` (новая зависимость).

## Тесты

Мок `openProject`/`createProject`: старт (кнопка + пустое состояние); `opened` → дерево с порядком детей;
клик → детали (название, подпись статуса, «Описание: нет»); сворачивание скрывает/возвращает детей;
`EMPTY_FOLDER` → запрос → [Создать] вызывает `createProject` → «В проекте нет нод»; [Отмена] — без вызова;
ошибка после открытого проекта → баннер с `code` и `problems`, старое дерево на месте; `cancelled` — без
баннера; легенда показывает 4 подписи. Ресайз — только вручную (jsdom не считает раскладку).

## Вне рамок
