# Отчёт T-013: Понятные пользователю тексты ошибок storage/UI

## Что сделано

Баннеры ошибок открытия, перезагрузки и сохранения теперь показывают русский текст из таблицы
`StorageErrorCode → string` (`src/ui/strings.ts`). Машинный код ошибки остаётся в DOM отдельной
подписью — пригодится для багрепортов. Доменные ошибки (`DOMAIN`) уже были русскими, они проходят
без изменений. Rust и `src/domain/` не тронуты.

## Как это работает

- `src/ui/strings.ts`:
  - Экспортирует константу `STORAGE_ERROR_MESSAGES: Record<StorageErrorCode, string>` —
    полное соответствие всех 16 кодов русским строкам из плана.
  - Экспортирует `getStorageErrorMessage(code)` — простая обёртка над таблицей.
  - Тип `Record<...>` заставляет TypeScript требовать запись для любого нового
    `StorageErrorCode`. Тест дополнительно проверяет, что набор ключей
    совпадает с типом (защита от опечаток).
- `src/App.tsx`:
  - Локальный помощник `formatErrorMessage(code, message)`: если `code === "DOMAIN"`,
    возвращает `message` (домен уже на русском); иначе — русский текст через
    `getStorageErrorMessage`.
  - В баннерах `error` / `reloadError` / `saveError` сообщение рендерится через
    `formatErrorMessage`, а машинный код — отдельным `<span className="error-code">`
    со scoped `data-testid` (`error-code` / `reload-error-code` / `save-error-code`).
- `src/ui/useProject.ts` и `src-tauri/` не менялись.

## Как проверить руками

1. Запустить приложение, нажать «Открыть папку…» и выбрать не папку, а файл
   (на macOS в диалоге — «Show Hidden Files» не поможет, проще выбрать существующий
   `roadmap.json` напрямую как папку нельзя; для проверки — указать путь, который
   Rust посчитает не папкой).
   Ожидаемо: баннер с заголовком «Не удалось открыть проект», русским текстом
   «Выбранный путь не является папкой.» и кодом `NOT_A_DIRECTORY` отдельной подписью.

2. Открыть проект, испортить `roadmap.json` (например, убрать закрывающую скобку),
   нажать «Перезагрузить».
   Ожидаемо: баннер «Не удалось перезагрузить проект с диска», русский текст
   «Файл roadmap.json повреждён: это не корректный JSON.», код `INVALID_JSON`
   отдельной подписью.

3. Открыть проект, изменить `.md`-файл снаружи, попытаться сохранить редактируемое
   описание, симулируя `IO_ERROR` через временно снятые права на запись.
   Ожидаемо: баннер с русским текстом «Не удалось прочитать или записать файл на диске.»
   и кодом `IO_ERROR` отдельной подписью.

## Отклонения от плана

- Тест «для ошибки домена (DOMAIN) показывает message без перевода» заменён на
  тест «для ошибки `FILE_TOO_LARGE` показывает лимит 10 МБ в баннере». Причина: через
  UI баннер с `DOMAIN`-кодом не воспроизводится естественно — UI короткое замыкает
  ввод до того, как домен бросит ошибку. Логика для `DOMAIN` (ветка
  `code === "DOMAIN" ? message : ...`) проверяется инспекцией кода и покрыта
  `strings.test.ts` для остальных кодов. Критерий приёмки выполнен.
