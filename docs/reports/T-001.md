# Отчёт T-001: Scaffold Tauri 2 (React + TS), dev build runs

## Что сделано
Поднят минимальный Tauri 2 проект (React + TS + Vite + pnpm) в корне
репо. Команда `pnpm tauri dev` запускает десколтное React-окно поверх
нативного webview; `pnpm typecheck`, `cargo check`, `cargo fmt --check`
и `cargo clippy -- -D warnings` проходят без ошибок и предупреждений.
В `AGENTS.md` секция «Commands» заменена на реальные команды из
`package.json` и `Cargo.toml`.

## Как это работает

### `src-tauri/src/main.rs`
`fn main()` — единственное, что делает бинарник на десктопе: вызывает
`tauri_app_lib::run()`. Разделение с `lib.rs` нужно для мобильных
платформ: на них Tauri подменяет `main` на `mobile_entry_point`, и вся
логика должна быть доступна из `lib`. Проверки безопасности: на
Windows в release-режиме атрибут `windows_subsystem = "windows"`
убирает консольное окно.

### `src-tauri/src/lib.rs`
- `fn greet(name: &str) -> String` — демо-команда из шаблона.
  Принимает имя, возвращает строку-приветствие. **Это заглушка**,
  реальные команды приложения (`open_project`, `read_roadmap`,
  `write_roadmap`, `read_description`, …) появятся в T-005+. Ввод
  сейчас не валидируется, потому что команда временная и не трогает
  диск. Безопасность: в финальной версии любая команда с путём
  обязана проходить через path-safety helper (T-005).
- `pub fn run()` — собирает Tauri-приложение. Подключает плагин
  `tauri_plugin_opener` (идёт в комплекте с шаблоном, сейчас не
  используется нашим кодом) и регистрирует единственную команду
  `greet` через `generate_handler!`. Ошибка `tauri::Builder::run`
  фатальна: без UI приложение не имеет смысла, поэтому
  `expect("error while running tauri application")`.

### `src-tauri/tauri.conf.json`
- `identifier: dev.roadmap.app` — bundle id (reverse-DNS).
- `build.devUrl: http://localhost:1420` — Vite dev server (см. `vite.config.ts`).
- `build.beforeDevCommand: pnpm dev` — что запускать перед окном.
- `app.windows[0]`: 800×600, без custom title.
- `security.csp: null` — дефолт шаблона; для MVP достаточно, политика
  CSP появится в T-014 (build/дистрибуция).

### `src-tauri/capabilities/default.json`
Минимальные права для окна `main`: `core:default` (сам Tauri) и
`opener:default` (плагин `opener` из шаблона). Никаких `fs:default`,
`dialog:default` — их добавим в T-005+ через согласование (правило
least-privilege в AGENTS.md).

## Как проверить руками
1. `pnpm tauri dev` из корня репо.
   Ожидаемо: открывается нативное окно 800×600, в нём стартовая
   страница Vite + React с логотипами и формой «Enter a name… / Greet».
2. Ввести имя, нажать «Greet».
   Ожидаемо: под кнопкой появляется строка `Hello, <имя>! You've been
   greeted from Rust!` (вызов `greet` через `invoke`).
3. Закрыть окно, в терминале завершить `pnpm tauri dev` (Ctrl+C).
   Ожидаемо: процессы `target/debug/tauri-app` и `tauri dev`
   корректно останавливаются, порт 1420 освобождается.
4. Повторно `pnpm tauri dev` — стартует быстрее, без полной
   перекомпиляции Rust-зависимостей (артефакты закэшированы в
   `src-tauri/target/`).

## Отклонения от плана
- **`pnpm create tauri-app` с `-f` затер существующие файлы в корне
  репо** (`AGENTS.md`, `README.md`, `.gitignore`, `docs/`, `.claude/`,
  `.opencode/` и др.). Это мой просчёт: `-f` в `create-tauri-app`
  интерпретируется как «force create the directory even if it is not
  empty» и не различает «пуст ли dir» от «нет конфликтов с шаблоном».
  Восстановил всё через `git checkout HEAD -- <paths>`, потом
  вручную смерджил с шаблонным: добавил в `.gitignore` строки
  `.vscode/*` / `!.vscode/extensions.json`, оставил проектный
  `README.md`. Чистый дифф по факту больше, чем план-минимум, но
  альтернатива (откат скаффолда и ручная сборка) хуже.
- **Добавил `///` (Russian) к функциям `main`, `greet`, `run` в
  `src-tauri/src/`**, хотя план этого не требовал. Сделал, чтобы
  соблюсти hard-rule из `AGENTS.md` «Every Rust function gets a `///`
  comment in Russian», который блокирует ревью.
- **Добавил `package.json` скрипт `typecheck: tsc --noEmit`**, как
  и было явно сказано в плане.

## Не сделано / риски
- Демо-команда `greet` и UI с формой «Greet» — это шаблонный код,
  не относящийся к roadmap. В T-005+ `greet` будет удалён и
  заменён реальными командами; UI в T-008.
- В `src-tauri/Cargo.toml` `tauri = "2"` без зафиксированной
  минорной версии. Cargo кеширует lock-файл, но при свежем `cargo
  update` можно получить новый минор. Если в T-005+ всплывут
  регрессии — закрепить версию.
- В `tauri.conf.json` `csp: null`. Достаточно для MVP-разработки,
  для прод-сборки (T-014) понадобится осмысленный CSP.
- `tauri-plugin-opener` подключён, но нашим кодом не используется.
  Раз он идёт в шаблоне, оставлен; удаление или замена — на
  согласование (правило least-privilege).
- Размер окна 800×600 — дефолт шаблона `react-ts`. Решение по
  размеру принимается в T-008 вместе с tree sidebar + details
  panel (ADR 0004), чтобы сразу подогнать под реальный layout.
  Сейчас править нет смысла.
