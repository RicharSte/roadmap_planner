# Отчёт T-011: Автосохранение описания, индикатор и предупреждение при закрытии

## Что сделано

Редактор описания теперь автоматически сохраняет изменения через 800 мс после последнего нажатия клавиши. Рядом с переключателем «Редактор/Просмотр» появляется надпись «Не сохранено», если черновик отличается от сохранённого текста или последнее сохранение завершилось ошибкой. При попытке закрыть окно приложения с несохранёнными правками выводится системный `confirm`; при согласии окно принудительно закрывается через `destroy()`.

## Как это работает

- `DescriptionEditor` держит `draft` (текущее состояние редактора) и `saved` (последний успешно записанный текст).
- При каждом изменении текста (`handleChange`) сбрасывается предыдущий таймер и запускается новый на 800 мс. По истечении времени вызывается `flush()`.
- `flush()` сравнивает `draftRef.current` и `savedRef.current`; если они отличаются, вызывает `onSave` и при успехе обновляет `saved`.
- Потеря фокуса (`handleBlur`) тоже вызывает `flush()` и очищает таймер, чтобы не было двойного сохранения.
- При размонтировании компонента сохранение происходит по старой логике (если `draftRef !== savedRef`), а отдельный эффект очищает debounce-таймер.
- Эффект на `[draft, saved]` сообщает родителю через `onDirtyChange`, есть ли несохранённые правки.
- `App` хранит флаг `descriptionDirty` и ошибку сохранения `saveError`; их объединение записывается в `hasUnsavedRef`.
- При монтировании `App` подписывается на `onCloseRequested` текущего окна. Если есть несохранённое состояние, вызывается `event.preventDefault()`, затем `window.confirm()`; при подтверждении — `getCurrentWindow().destroy()`.
- Rust-команды не изменялись; добавлено только разрешение `core:window:allow-destroy`, ограниченное окном `"main"`.

## Как проверить руками

1. `pnpm tauri dev` → открыть проект с описанием ноды.
2. Ввести текст в редакторе описания, не кликать вне поля.
3. Убедиться, что рядом с переключателем появилась надпись «Не сохранено».
4. Подождать примерно 1 секунду — надпись исчезает; в папке проекта `descriptions/<id>.md` появился введённый текст.
5. Ввести текст снова и сразу нажать закрытие окна (красная кнопка/крестик).
6. Должен появиться системный `confirm` с предупреждением.
7. «Отмена» — окно остаётся, текст в редакторе на месте.
8. «ОК» — окно закрывается; при повторном открытии проекта текст сохранён.
9. `Cmd+Q` на macOS: ожидается тот же путь через закрытие единственного окна; если обходит — эскалация.
