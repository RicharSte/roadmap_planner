## Как это работает

- **ESLint**. Flat-конфиг собирает `@eslint/js/recommended`, `typescript-eslint/recommended` (без типовой информации), правила React Hooks и React Refresh, а в конце `eslint-config-prettier` отключает конфликтующие правила. `pnpm lint` запускает `eslint . --max-warnings 0`, поэтому любое предупреждение ломает сборку.
- **Prettier**. Конфигурация живёт в `package.json`: `printWidth: 100`, остальное — умолчания. `pnpm format` форматирует весь репозиторий, `pnpm format:check` проверяет без записи. `.prettierignore` исключает служебные каталоги агентов и lock-файл.
- **Vitest**. Блок `test` внутри `vite.config.ts` задаёт окружение `jsdom`, указывает `setupFiles: ["./src/test/setup.ts"]` и отключает `globals`, поэтому в тестах явный импорт `describe/it/expect` из `vitest`.
- **Smoke-тест**. `App.test.tsx` рендерит компонент и проверяет, что на странице есть заголовок «Welcome to Tauri + React». Tauri не вызывается, мок не нужен.
- **Rust**. Функции не менялись: `greet` принимает имя и возвращает приветствие; `run` собирает приложение; `main` делегирует `run`. Проверки `cargo fmt --check`, `cargo clippy` и `cargo test` проходят.

## Как проверить руками

1. `pnpm lint` — без ошибок.
2. Добавьте в `src/App.tsx` строку `const unused = 1;` → `pnpm lint` падает с `no-unused-vars`; удалите строку → проходит.
3. Испортите отступ в `src/App.tsx` → `pnpm format:check` падает; `pnpm format` чинит → `pnpm format:check` проходит.
4. `pnpm typecheck`, `pnpm test` — проходят.
5. В `src-tauri/` выполните `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` — проходят.
