# Отчёт T-007: Создание нового проекта

## Что сделано

Появилась возможность создать новый проект в уже выбранной пустой папке. Раньше `open_project` оставлял пустую папку как кандидата, но превратить её в проект было нельзя. Теперь бэкенд умеет создавать `roadmap.json` и папку `descriptions/` атомарно, а фронтенд — собирать пустой проект v1 и передавать его в Rust.

## Как это работает

### Rust

- **`has_visible_files(dir)`** — читает содержимое папки и возвращает `true`, если есть хотя бы один файл, имя которого не начинается с `.`. Скрытые файлы игнорируются, чтобы `.DS_Store` не мешал создавать проект. При ошибке чтения возвращает `IO_ERROR`. Этот хелпер вынесен из `read_roadmap`, чтобы одна и та же проверка использовалась и при чтении существующего проекта, и при создании нового.
- **`ProjectState::create(content)`** — создаёт проект в кандидате вида `Empty`:
  1. Если кандидата нет — `NO_PENDING_PROJECT`.
  2. Если кандидат уже является проектом (`Roadmap`) — `PENDING_NOT_EMPTY`.
  3. Если папка перестала быть пустой после выбора в диалоге — `FOLDER_NOT_EMPTY`.
  4. Если переданный `content` не валидный JSON — `INVALID_JSON`, при этом ничего на диск не пишется.
  5. Иначе создаётся папка `descriptions/`, `roadmap.json` записывается атомарно через `write_inside`, а кандидат становится открытым проектом (`root`).
- **`create_project(state, content)`** — Tauri-команда, которая вызывает `ProjectState::create`. Возвращает пустой `Ok(())` при успехе.

### TypeScript

- **`createEmptyProject()`** — возвращает `{ version: 1, rootIds: [], nodes: {} }`. Этот объект проходит и `parseProject`, и `validateProject`.
- **`createProject()`** — строит пустой проект, прогоняет его через `validateProject`, сериализует с отступом 2 и завершающим переводом строки, вызывает `invoke("create_project", { content })`. При успехе возвращает `{ kind: "opened", project }`, при ошибке — `fromRustError`.

## Как проверить руками

Ручная проверка отложена до появления UI-кнопки в T-008/T-009. В коде можно проверить так:

1. Вызвать `open_project` и выбрать пустую папку — Rust запомнит её как `Empty`.
2. Вызвать `create_project` с валидным JSON пустого проекта.
3. Ожидаемо: в папке появятся `roadmap.json` и `descriptions/`, проект станет открытым.
