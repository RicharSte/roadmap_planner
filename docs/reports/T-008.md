# Отчёт T-008: UI — дерево в сайдбаре + панель деталей

## Что сделано

Реализован основной интерфейс просмотра проекта. Пользователь видит дерево нод, их статусы, может сворачивать ветки, выбирать ноду и видеть её детали. Пустая папка предлагает создать в ней новый проект. Ошибки открытия показываются баннером, при этом прежний проект остаётся на экране. Сайдбар можно растягивать мышью.

## Как это работает

- `useProject()` хранит `project`, `selectedId`, `collapsed`, `error` и `pendingCreate`. Индекс родителей строится через `useMemo(buildParentIndex)` при смене проекта.
- `open()` вызывает `openProject()`. При успехе сбрасывается выбор и свёрнутые узлы. При `EMPTY_FOLDER` появляется диалог создания. При других ошибках — баннер, старый проект не трогается.
- `create()` вызывает `createProject()` и загружает пустой проект.
- `TreeSidebar` рендерит корни из `rootIds`, затем рекурсивно детей через `getChildren`. Каждая строка — нативная кнопка; треугольник сворачивания — отдельная кнопка, чтобы клик по ней не менял выбор.
- `DetailsPanel` показывает «Выберите ноду», «В проекте нет нод» или данные выбранной ноды: название, статус (точка + подпись), даты `toLocaleString`, путь к описанию или «нет».
- В `App.tsx` разделитель мышью ограничен 180px…60% ширины окна, стартовая ширина 280px. Обработчики `mousemove`/`mouseup` вешаются на `window` только во время перетаскивания.
- Rust-функции в этой задаче не добавлялись и не изменялись.

## Как проверить руками

1. `pnpm tauri dev`. Нажать «Открыть папку…», выбрать пустую папку.
   Ожидаемо: появляется строка «Папка пуста. Создать в ней новый проект?» и кнопки [Создать]/[Отмена].
2. Нажать [Создать].
   Ожидаемо: в папке появляются `roadmap.json` и `descriptions/`, в правой панели «В проекте нет нод».
3. Создать в папке вручную `roadmap.json` с несколькими нодами (через `childrenIds` и `rootIds`), открыть её.
   Ожидаемо: дерево отображается в порядке `childrenIds`, все ветки раскрыты.
4. Кликнуть на ноду.
   Ожидаемо: в панели деталей название, статус с подписью, даты создания/изменения, описание.
5. Свернуть и развернуть ветку треугольником.
   Ожидаемо: дети скрываются и появляются снова.
6. Проверить цвета точек по легенде внизу сайдбара.
   Ожидаемо: серый / синий / красный / зелёный для четырёх статусов.
7. Потянуть разделитель.
   Ожидаемо: ширина меняется в пределах 180px…60%, при узком окне появляется горизонтальный скролл, раскладка не ломается.
8. Выбрать папку без `roadmap.json`.
   Ожидаемо: баннер «Не удалось открыть проект» с кодом `NO_ROADMAP_FILE`, прежний проект остаётся виден.
