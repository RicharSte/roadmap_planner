# Architecture Decision Records

One file per decision: `NNNN-short-title.md`. Keep each under ~30–50 lines.
0015 is reserved for T-102 (reload error locks writes).
When a decision changes, write a new ADR and add `(amended by NNNN …)` / `(superseded by NNNN)` to the old status line.

Template:

```
# NNNN. Title
Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
