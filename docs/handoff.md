## Контекст для T-015

- Найдено в `docs/mvp-done.md`: «Windows: сборка `.msi`/`.exe` (T-015; способ — Windows-машина
  или GitHub Actions, решает пользователь)». Конкретный способ не выбран — это первое решение
  для интервью.
- Сейчас в проекте нет ни Windows-машины в рабочей среде, ни GitHub Actions, ни публичных
  релизов. Запланировано в `docs/later.md` T-108 (CI + релиз 1.1). T-015 — это узкая задача:
  убедиться, что `pnpm tauri build` отрабатывает на Windows, и выдать `.msi`/`.exe`.
- Решение «как собирать» сильно зависит от того, доступна ли пользователю Windows-машина
  (физическая или VM) или он хочет CI с самого начала. Без ответа план не составить —
  минимум три развилки:
  1. **Локальная Windows-машина / VM** — простой `pnpm tauri build` → `.msi`/`.exe`.
     Одноразовая сборка, но требует от пользователя окружения Windows с Rust + Node + WebView2.
  2. **GitHub Actions** — кросс-платформенный CI с матрицей `windows-latest` +
     `macos-latest`. Требует workflow-файла и, обычно, подписи `.msi` (WiX/ev簽). Без подписи
     SmartScreen будет ругаться.
  3. **Cross-build на macOS** (через `cargo-xwin` + `pnpm tauri build --target`) — удобно
     для разработчика, но официально не поддерживается Tauri 2 «из коробки» и часто ломается
     на плагинах окна.
- Риск по `mvp-done.md`: пункт про Windows — единственный, блокирующий MVP после T-014.
  Все остальные пункты `docs/mvp-done.md` либо отмечены, либо подтверждаются пользователем
  в собранном macOS-`.app` (раздел «Сценарии пользователя»). Если ручной прогон по
  сценариям пользователя в T-014 ещё не сделан — его нужно закончить до T-015, иначе MVP
  не закрыть.

## Что не забудь при T-015

- Перед планом — спросить пользователя про способ сборки (см. выше три развилки).
- Если выбран GitHub Actions: не делать подпись/нотаризацию в этой задаче — это
  `docs/later.md` (T-301, подпись/нотаризация). В этом MVP достаточно неподписанного `.exe`
  с инструкцией «ПКМ → свойства → «Разблокировать»» или SmartScreen-предупреждением.
- Если выбран локальный Windows: подготовить короткую шпаргалку по пред-установке
  (`rustup target add x86_64-pc-windows-msvc`, WebView2 runtime), иначе сборка упадёт
  непредсказуемо.
- Кросс-сборку с macOS в плане не предлагать — Tauri 2 её не любит, и профит сомнителен.
- Иконка приложения сейчас шаблонная (стандартный набор в `src-tauri/icons/`). Если T-015
  захочет использовать те же иконки на Windows — Tauri обычно подхватывает `icon.ico`
  автоматически, проверь `tauri.conf.json` → `bundle.icon` (там уже есть `icon.ico`).
