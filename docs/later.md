## Web (направление, требования не утверждены)

Следующий большой шаг после MSP. Здесь только контекст, чтобы решения MSP не мешали.

- Люди создают и проходят свои roadmap в вебе; могут их продавать.
- Монетизация — через «невыполнение»: пользователь ставит обязательство (дедлайн + критерии),
  не выполнил — теряет залог. Нужны проверяемые критерии приёмки и дедлайны (уже есть в формате v2).
- Десктоп остаётся бесплатным.
- Что уже готово: домен без Tauri (`src/domain/`), версия формата + миграции, zip-пакет проекта (ADR 0022),
  каталог (ADR 0021) как прообраз витрины.
- Чего нельзя ломать: данные пользователя остаются в его папке и читаются без приложения; базовый сценарий
  работает офлайн и без аккаунта.
- ID задач веба: `W-xxx`.
